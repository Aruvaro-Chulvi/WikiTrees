# Community trees · Árboles de la comunidad

One folder per approved tree: `community/<github-user>.<slug>/`

| File | |
|---|---|
| `tree.json` | The tree, in the [community format](../community-kit/FORMAT.md). |
| `cover.png` | Optional cover image. |
| `submission.json` | Who sent it, when, from which issue, and the licence chosen. |

Read [CONTRIBUTING.md](../CONTRIBUTING.md) to send a tree. · Lee [CONTRIBUTING.es.md](../CONTRIBUTING.es.md)
para enviar un árbol.

`retired.json` lists withdrawn trees (`[{"id": "c.user.slug", "reason": "…"}]`): they are not published
any more and Offlined stops offering them. Deleting a folder withdraws the tree too.

Community trees: each by its author, under the licence in its `meta.license` —
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) or [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(the cover too). The official trees are under [CC BY-NC-SA 4.0](../LICENSE).
